# Working together

We are [Snehal Jindal](https://github.com/snehal-jindal) and [Lexie Lin](https://github.com/Lexielinnnnn).

We use focused branches and pull requests to review changes to our data, analysis and documentation.

1. Create a branch for the change.
2. Explain what changed and why in the PR.
3. Run `python -m unittest discover -s tests -v` and `python scripts/run_analysis.py`.
4. Ask the other team member to review the code and interpretation.
5. Address review comments before merging, and keep the report and slides aligned with the generated results.
