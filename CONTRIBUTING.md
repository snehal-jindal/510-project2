# Collaboration and review

Snehal Jindal and Lexie Lin are the project authors. Do not create commits or approvals impersonating the other partner. AI-assisted implementation is disclosed in the README.

For a meaningful teammate contribution:

1. Clone the repository with your own GitHub account and create a focused branch.
2. Independently check a real part of the study: e.g. verify the power enumeration, audit the data dictionary against the data, or add a justified sensitivity analysis with documented assumptions. Do not merely change a space for a token PR.
3. Run the tests and complete pipeline. Open a PR describing the change and evidence.
4. Request the other partner’s review. Discuss concrete findings, address comments, resolve conversations and merge after checks and review.
5. Add the final written-report link and, if applicable, video link to the README. Recheck report/deck numbers against generated results.

The initial implementation PR may be published before the partner is available. Its existence is not a claim that independent peer review has already happened. The rubric’s two-author contribution/review requirement remains pending until both people actually complete it.
